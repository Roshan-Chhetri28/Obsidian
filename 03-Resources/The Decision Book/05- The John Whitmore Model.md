## Am I persuing the right goal?
- While setting goals you should distinguish between final and performance goal.
- Example: suppose you want to run a marathon then 
	- Final goal is to run a marathon.
	- performance goal is to go jogging for thirty minutes every morning.
*Note: If a goal is unattainable, there is no hope, and if it is not challenging it will kot motivate you.*
